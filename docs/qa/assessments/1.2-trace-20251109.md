### Test Design Recommendations

1. Add Helm-focused checks for CronJob and object storage templates when `objectStorage.enabled` toggles on/off.
2. Create integration harness leveraging moto/MinIO with namespace-prefixed buckets to exercise OCI configuration end-to-end. ✅ (MinIO pipeline covers primary flow; extend to namespace-path scenarios.)
3. Automate lifecycle policy verification via infrastructure tests or policy-as-code checks in CI. ✅ (MinIO lifecycle test validates command; extend to OCI-native environments.)
4. Add validation hook ensuring object storage credentials are provided before enabling restore-on-startup to prevent silent skips.

- **High Risk:** None – core backup/restore logic has automated coverage.

- **Low Risk:** Lifecycle policy and MinIO flow covered in automation, but native OCI validation remains a future improvement.
