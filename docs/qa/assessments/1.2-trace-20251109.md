### Coverage Gaps

1. **AC5 – Configuration documentation**
   - Gap: Documentation-only verification; no automated guard for required values
   - Severity: low
   - Suggested Test: Introduce smoke test that ensures critical `objectStorage` keys are non-empty when feature enabled

### Test Design Recommendations

1. Expand Helm-focused tests to assert CronJob and init container rendering when `objectStorage.enabled` toggles on/off.
2. Create integration test harness leveraging moto or MinIO with namespace-prefixed buckets to exercise OCI configuration end-to-end.
3. Automate retention policy verification through infrastructure tests or policy-as-code checks in CI.
4. Add validation hook ensuring object storage credentials are provided before enabling restore-on-startup to prevent silent skips.

### Risk Assessment

- **High Risk:** None – core backup/restore logic has automated coverage.
- **Medium Risk:** AC4 and AC7 rely on manual validation; missing automation could let configuration regressions slip.
- **Low Risk:** AC5 and AC8 documentation-only verifications; impact mitigated by operational runbooks.
