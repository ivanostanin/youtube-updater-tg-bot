## Risk Coverage

- **REL-001** (startup crash when storage config absent) mitigated by scenarios 1.2-INT-001 and 1.2-INT-002.
- **TEST-001** (CLI lacks regression coverage) mitigated by scenarios 1.2-INT-001 and 1.2-UNIT-006.

## Recommended Execution Order

1. P0 unit tests (1.2-UNIT-001, 1.2-UNIT-003, 1.2-UNIT-004)
2. P0 integration tests (1.2-INT-001, 1.2-INT-002, 1.2-INT-006)
3. P0 E2E drill (1.2-E2E-001)
4. Remaining P1 unit/integration tests (1.2-UNIT-002, 1.2-UNIT-005, 1.2-UNIT-006, 1.2-INT-003, 1.2-INT-003A, 1.2-INT-004, 1.2-INT-005)

## Coverage Gaps & Notes

- AC5 still relies on documentation; add Helm render assertions or policy-as-code checks to guard required `objectStorage.*` keys.
- Ensure CI environments provide Docker and Helm so integration suites (`1.2-INT-003`, `1.2-INT-003A`, `1.2-INT-006`, `1.2-INT-005`) execute consistently.
