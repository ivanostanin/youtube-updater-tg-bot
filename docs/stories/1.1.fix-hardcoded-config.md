### Configuration Management
**[Source: architecture/3-tech-stack.md#3.1]**
- **Validation Library:** Pydantic 2.11.10 for data validation
- **Settings Management:** pydantic-settings 2.11.0 for environment configuration
- **Pattern:** Settings class extends BaseSettings with Field() descriptors

**Current Configuration Structure [Source: src/utils/config.py]:**
```python
class Settings(BaseSettings):
    telegram_bot_token: str = Field(..., description="Telegram Bot Token from BotFather")
    youtube_api_key: str = Field(..., description="YouTube Data API v3 Key")
    database_url: str = Field(default="sqlite+aiosqlite:///./bot.db", description="Database URL")
    webhook_host: str = Field(default="localhost", description="Webhook host for receiving notifications")
    webhook_port: int = Field(default=8000, description="Webhook port")
    webhook_path: str = Field(default="/webhook", description="Webhook path")
    log_level: str = Field(default="INFO", description="Logging level")
```

  - **Why**: Pydantic V2.0+ deprecated class-based config; will be removed in V3.0
  - **How**: Replaced `class Config:` block with `model_config = ConfigDict(...)` attribute
